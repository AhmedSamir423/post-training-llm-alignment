# post-training-llm-alignment
This project is an experimental deep dive into the trade-offs and complexity of aligning Large Language Models (LLMs). 1. Full Fine-Tuning (FFT) on a small encoder model with a Language Modeling (LM) head. 2. Parameter-Efficient Fine-Tuning (PEFT) for skill acquisition (SFT). 3. Direct Preference Optimization (DPO) for behavioral alignment.
